## 1. 项目是什么

一个中文技术博客项目，主题是 **《大语言模型 Agent 技术详解：从工具调用到自主任务执行的工程实践》**。面向有 LLM、后端或系统架构基础的工程师，要求技术细节充分、有工程视角、避免营销式表达。

文章的核心论点：

- Agent 不是提示词技巧，也不是一次函数调用，而是一套系统架构；
- Agent 的能力 = 模型 + 工具 + 记忆 + 规划 + 控制；
- 企业落地优先关注边界、权限、安全、评估与成本，而不是"模型更聪明"。

## 6. 修改指南

### 6.1 改正文

1. 只改 `大语言模型Agent技术详解.md`；

### 6.2 新增或替换配图

1. 在 `images/` 新建 SVG，文件名 `figNN-slug.svg`，NN 按正文出现顺序递增；
2. SVG 根元素必须写成 `<svg ... width="750" height="H" viewBox="0 0 750 H">`，渲染脚本靠这个读尺寸；
3. 运行 `python3 render_diagrams.py`，确认输出 `figNN-slug.png: 1500×2H`；

5. 在正文首次提到该概念的位置插入：


## 7. 写作规范

### 7.1 风格

- 中文技术博客，先给结论，再讲机制，再给工程做法和失败模式；
- 每个核心概念尽量覆盖：职责、常见实现、工程挑战、与其他模块的关系；
- 允许明确说"这是工程经验"或"这是示意值"，不要伪装成实测结论；
- 不用"赋能、颠覆、革命性、最强"等营销词；
- 长段落拆短，表格用于对比，代码块用于可执行逻辑。

### 7.2 术语

保持全文一致：

| 术语 | 用法 |
|---|---|
| Agent | 不翻译；"智能体"只在必要处括注 |
| Orchestrator | 编排器 / 执行控制器 |
| Planner / Executor | 规划器 / 执行器，首次出现可括注英文 |
| Observation | 观察结果，不写"观测值" |
| Reflection | 反思 / 反思校验 |
| 完成判据 | 不写"成功标准"混用 |
| 降级交付 | 预算耗尽时带缺口输出，不用"兜底输出" |
| Trace | 不翻译 |

### 7.3 事实与假设

- 数字一律标"示意"或"量级"，不写成 benchmark；
- 框架对比只讲能力层面，不绑定版本 API；
- 涉及安全能力时，明确边界，不承诺"绝对防护"；
- 引用外部事实时给来源；没有来源的推断要写明是推断。

### 7.4 代码

- 主稿伪代码保持 Python 风格，突出控制流，不追求可直接运行；
- 如果新增真实代码，单独标注依赖与版本，并说明与伪代码的区别；
- 代码块单行尽量 ≤100 字符，方便后续公众号重排。

## 8. 配图规范

### 8.1 画布与输出

- 画布宽固定 **750px**，高度按内容定；
- 通过 `render_diagrams.py` 输出 **2x PNG**；
- 背景纯白 `#ffffff`；
- 字体统一：`'PingFang SC','Hiragino Sans GB','Microsoft YaHei',sans-serif`；
- 可在根节点用一个 `<g font-family="...">` 包住所有文本，减少重复。

### 8.2 字号与层级

| 层级 | 字号 | 颜色 |
|---|---|---|
| 主标题 | 28–30，bold | `#0f172a` |
| 副标题 | 16 | `#64748b` |
| 模块标题 | 15–19，bold | `#0f172a` |
| 正文标签 | 12–14 | `#334155` / `#475569` |
| 注释 / 次要说明 | 10–11 | `#64748b` / `#94a3b8` |

注意：750px 画布在手机上会缩到约 390px，10px 文字只剩约 5px。若明确面向公众号，关键信息不要小于 12px，正文标签尽量 14px 以上；当前图更偏向桌面 / 博客阅读。

### 8.3 配色

| 用途 | 色值 |
|---|---|
| 深色主块 / 标题 | `#0f172a` |
| 主流程蓝 | `#2563eb`，浅底 `#eff6ff`，边框 `#bfdbfe` / `#93c5fd` |
| 能力 / 结果青 | `#0f766e`，浅底 `#f0fdfa`，边框 `#5eead4` / `#99f6e4` |
| 反馈 / 警示橙 | `#d97706`，浅底 `#fffbeb` / `#fff7ed`，边框 `#fcd34d` / `#fdba74` |
| 协作紫 | `#7c3aed`，浅底 `#f5f3ff`，边框 `#c4b5fd` |
| 风险红 | `#dc2626`，浅底 `#fef2f2`，边框 `#fca5a5` |
| 中性灰 | 文字 `#64748b`，底 `#f8fafc`，边框 `#e2e8f0` |

### 8.4 连线与形状

- 主流程：实线，`stroke-width` 2–2.4，蓝色箭头；
- 反馈 / 重规划：虚线 `stroke-dasharray="4 4"` 或 `"5 5"`，橙色箭头；
- 箭头 marker 尺寸 7–8，`refX` 设为 6–7，避免箭头压住框线；
- 圆角：小卡片 7–10，大卡片 12–16，胶囊 22–24；
- 一屏内不要超过 3 种强调色，否则层级会乱。

### 8.5 图注与命名

- 文件名 `figNN-slug.svg`，与正文顺序一致；
- 图注格式固定为 `*图 N：一句话说明。*`；
- 图注放在图片下一行，前后各空一行；
- 图注不重复正文原句，只补充"这张图在说什么"。

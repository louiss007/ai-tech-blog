## 4. 配图生成流程

配图的唯一源文件是 `images/*.svg`，PNG 是渲染产物，**不要手改 PNG**。

```bash
cd llm_agent
python3 render_diagrams.py
```

依赖：

- Python 3；
- `playwright`（已安装，3.13.12 环境下验证通过）；
- Chromium（Playwright 自带浏览器，已可用）。

重新渲染会覆盖全部同名 PNG。设计规范（画布 750px 宽、正文关键标签 15–19px、2x 导出、配色与字体）见 `CLAUDE.md` 第 8 节。

## 8. 已知限制与风险

1. **数字是示意值**：文中的成功率、延迟、成本、步数均为量级示意，不是实测或 benchmark 结果，正文开头已声明。
2. **框架 API 不绑定版本**：LangChain、LlamaIndex、AutoGen、LangGraph 等迭代快，文章只讲能力层面，落地时需查对应版本文档。
3. **没有参考文献与逐条引用**：所有事实性表述来自公开常识与工程经验，未做学术式引用；若要更严谨，需补 P1 中的文献。
4. **§6 的框架对比是流程演示**：LangChain / LlamaIndex / AutoGen 只是示例对象，文中结论不构成选型建议。
5. **图片是本地路径**：Markdown 预览正常；公众号或第三方编辑器需要手动上传 PNG。
6. **未做移动端适配**：22 张表中多张是 5 列以上，公众号直接粘贴会挤；需要按平台重排。
7. **篇幅偏长**：20197 汉字，单篇完读率有风险；这也是建议评估拆分连载的原因。
8. **安全章节是防御建议**：Prompt Injection 没有模型层的完美解法，文中已明确"靠权限与审批兜底"，不要理解成"按文中做就绝对安全"。

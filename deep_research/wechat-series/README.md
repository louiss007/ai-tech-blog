## 如何粘贴到公众号

**方法 A（推荐）**

1. 用浏览器打开 `partX.html`；
2. `Cmd+A`（Mac）或 `Ctrl+A`（Windows）全选，复制；
3. 公众号后台新建图文，标题单独填写；
4. 粘贴到正文，手机预览检查代码块和表格。

**方法 B**

用 mdnice、Md2All 等工具导入 `partX.md`，选择深色代码主题后复制到公众号。
